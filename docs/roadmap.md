# Roadmap

## Milestone 0: executable architecture

- Versioned protocol and JSON schema
- Explainable compatibility and placement scheduler
- Loopback controller API with persistent jobs
- Windows capability probe and diagnostic CLI
- Codex Skill and MCP bridge
- Desktop dashboard shell

## Milestone 1: Windows private preview

- Signed Windows controller installer
- Managed Worker pairing and device identity
- Existing SSH import
- Source snapshot and Git SHA synchronization
- Job-owned execution, cancellation, verification, and artifact collection
- Additive Codex integration installer and rollback

## Milestone 2: heterogeneous fleet beta

- Linux worker and installer
- macOS worker capability probe
- Resource leases and concurrent Codex session isolation
- GPU, container, and cache-aware scheduling
- Update channels and migration rollback

## Milestone 3: public release

- Windows and macOS controller packages
- Localization, accessibility, and guided diagnostics
- Signed updates, SBOM, reproducible release evidence
- Documented compatibility matrix and stable v1 protocol
